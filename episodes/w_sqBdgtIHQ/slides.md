# Sam Altman 的三条新要求

<div class="text-sm opacity-60 mb-4">"OpenAI 的条件非常苛刻，对最重要的三项投资权益都有非常重大的条件改变。"</div>

# 后训练阶段的两种主要标注

<div class="text-sm opacity-60 mb-4">标注主要出现在模型的"后训练 / 微调"阶段：</div>

<div class="grid grid-cols-2 gap-6 mt-4">

<div class="p-5 rounded bg-green-50 border-l-4 border-green-500">

### RLHF（人类反馈强化学习）

人类的角色是**帮模型判断哪种答案更符合偏好**。

> "ChatGPT 给出两个回答，大多数人会更喜欢第二个。
> 模型就会根据这种反馈学习——
> '哦，第二种回答更好，我以后要做出更多那样的回答'。"

</div>

<div class="p-5 rounded bg-orange-50 border-l-4 border-orange-500">

### Supervised Fine-tuning（SFT）

> "它更像是'专家自问自答'。"

当问题**没有现成的优质数据**，或涉及非常专业的知识时，需要专业标注人员**亲自构建回答**，把高质量语料喂给模型继续训练。

</div>

</div>

<div class="mt-6 p-4 rounded bg-blue-50 border-l-4 border-blue-500 text-sm">
Scale 的优势：<strong>在这两种复杂的微调场景下都能提供高质量服务。</strong>
</div>

# 四件事之 ①②｜材质 + 用户调整

<div class="grid grid-cols-2 gap-6 mt-4">

<div class="p-5 rounded bg-green-50 border-l-4 border-green-500">

### ① 材质创新 + 中国供应链

工艺创新：**搪胶毛绒玩具**——
搪胶（一种特别软的塑料）+ 毛绒结合，"立体、像在撸猫"。

- 投入上千万的**模具开发费用**
- 一下子出了 6 个系列、近 100 多款公仔
- 中国供应链把搪胶毛绒玩具售价**降到一百多块**——极大扩展用户群

衍生：娃衣、汽车座椅、小手提包。

<div class="text-xs opacity-60 mt-2">"我就很喜欢把它别在特斯拉的中控屏上。"</div>

</div>

<div class="p-5 rounded bg-orange-50 border-l-4 border-orange-500">

### ② 根据用户需求做调整

LABUBU 最初是一个 **"邪神"** ——
在龙家升的绘本里更邪恶一些。

后来双方合作：
- 改得**更可爱**，保留"一点搞怪的邪恶感"
- 眼睛变得**水汪汪**
- 从小众形象 → 大众更能接受

<div class="mt-4 text-xs opacity-70">
泡泡玛特作为 IP 运营公司，背后有"一整套数据库的积累，它知道大众喜欢什么"。

# 历史对标：LABUBU 像谁？

<div class="grid grid-cols-2 gap-6 mt-4">

<div class="p-5 rounded bg-pink-50 border-l-4 border-pink-500">

### 更像芭比

> "芭比是美泰公司制造出来的玩具，一开始它也是没有内容的。"
> ——"芭比"这个名字来自创造者 Ruth 女儿的名字。

美泰抓住了**电视媒介的快速普及**：
- 铺天盖地的电视广告造势
- **开创了新的玩具品类**
- 撑起美泰公司 1/3 的营收

→ "开创品类、利用媒体造势、形成全民共识"——
**LABUBU 和芭比是有非常相近的地方的。**

</div>

<div class="p-5 rounded bg-yellow-50 border-l-4 border-yellow-500">

### Hello Kitty 的三层收入

1. **商品销售与授权**：文具、服装、家居、电子产品
2. **媒体合作**：动画、电子游戏、漫画 + 跨界
3. **主题乐园**：三丽鸥彩虹乐园

泡泡玛特也在沿这条路走：
- LABUBU 出到**第三代**，年底/明年初出**第四代**
- **泡泡玛特积木**刚在美国上市，已售罄
- **时尚珠宝**：400-2000 元，银或 14K 金
- **Pop Land 主题公园**：北京朝阳公园
- 今年夏天："**The Monsters 动画迷你剧**"

# 22-23 的质疑，今天还成立吗

<div class="grid grid-cols-2 gap-6 mt-4">

<div class="p-5 rounded bg-red-50 border-l-4 border-red-500 text-sm">

### 当时的担心
- **过度依赖头部 IP**
- 头部 IP 增长乏力（Molly 收入从 5 亿 → 3 亿+）
- 新孵化 IP 卡在几千万到 1-2 亿规模
- 同店业绩下滑、开店变慢、回本周期拉长

</div>

<div class="p-5 rounded bg-green-50 border-l-4 border-green-500 text-sm">

### 现在的解法
> "当时的质疑其实不是被完全解决，而是被**稀释了**。"

- 形成**丰富的 IP 矩阵**：2024 年 **4 个 IP 收入超过 10 亿**
- **盲盒之外的新产品形态**：搪胶毛绒推到 Molly 等其他 IP，延长 IP 生命周期
- **出海**：东南亚、北美的成功 → "**强劲的第二增长曲线**"

</div>

</div>

<div class="mt-6 p-4 rounded bg-blue-50 border-l-4 border-blue-500 text-sm">

### 天花板？
中国 IP 市场，2024 年**人均消费大约只有 100 元人民币**——

而美国 **3000 多**、日本 **500 多**、全球 **200 多** ——
**"还差了很多。"**

</div>
