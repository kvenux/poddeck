# 成本结构变了：SaaS vs Token

旧模型——做 SaaS 产品：

- 研发是 **一次性投入**
- 用户越多，**边际成本趋近于零**
- 「越卖越赚」的生意

<br/>

新模型——做 Token App：

- 每个用户每次操作，都有一笔 **token 账单**
- 用户用得越深、功能越智能，**你付给模型厂商的钱越多**
- 成本 **跟着用量线性增长**，摊不薄

# 反直觉悖论：越贵的模型，总成本反而越低

<div class="grid grid-cols-2 gap-6 mt-4">

<div class="p-5 rounded bg-red-50 border-l-4 border-red-500">

### ❌ 弱模型，便宜的悖论
- 反复重试、来回 iteration（迭代）
- 中间可能出错 → 还要 **人工介入**
- 一个任务跑了好几轮 agent loop

**综合成本** 反而更高

</div>

<div class="p-5 rounded bg-green-50 border-l-4 border-green-500">

### ✅ 强模型，贵但是值
- 一次就生成想要的答案
- 调用的工具是合适的
- 工具返回的 output 也是你要的

**每个有效结论的成本反而在下降**

</div>

</div>

<div class="mt-6 p-4 bg-blue-50 border-l-4 border-blue-500 italic">
「虽然 token 价格在涨，但是每个有效结论的成本反而在下降。」<br/>
—— 在 agent 场景下尤其明显

# Agent loop：吞 token 的怪兽

Agent 不是「一问一答」——它会：

- 来回调用模型
- 每一步可能调用不同的工具
- 工具产生 **新的日志和上下文**
- 继续 **循环调用**

最终的 token 数取决于 **agent loop 跑了多少轮**。

<div class="mt-4 p-3 bg-red-50 border-l-4 border-red-500 text-sm">
<strong>作者概括</strong>：业内人士批评——「当前全球企业 AI 应用当中，可能有近一半的 token 没有产生实际价值。」
</div>

<div class="mt-2 text-xs opacity-60">
Agent 不像人类那样知道「够了就停」——它会反复读取整个对话历史、重新扫描已处理过的文件，把早就过期的上下文一遍又一遍喂给模型。
</div>

# 中国模型为什么能这么便宜？

<div class="grid grid-cols-3 gap-4 mt-6">

**深度 MoE（混合专家模型）**
- 专家的 size 越来越小
- 每一次 active 的专家数目不大
- 通过这种方法在技术上节省

<div class="p-4 rounded bg-orange-50 border-l-4 border-orange-500">

### ② 生态
**补贴用户、抢占生态**

通过低价快速做大调用量、绑定开发者。

<div class="p-4 rounded bg-purple-50 border-l-4 border-purple-500">

### ③ 云厂商身份
中国的某些公司本身就是云厂商（如 **阿里**）——

自己的成本定价可以比外面计价更低，有更高的 **margin（利润率）** 去把模型价格打下来。

</div>

**👨‍💻 程序员的真实感受**：「开源模型可能跟几个月前的 Anthropic 模型一样好用，但是价格又极其便宜的时候，他们自然而然就会切换到开源模型。」<br/>
很多任务其实并不需要那么高的推理能力——执行需要的是「**instruction following 比较好、做得比较快、最重要的还是便宜**」。

# Metronome：给 Token 装电表的人

<div class="grid grid-cols-2 gap-6 mt-4">

<div>

### 客户名单
**OpenAI · NVIDIA · Anthropic · Databricks**——全在用同一家公司的计费系统。

### 创始人背景
两位创始人都出自 **Dropbox**——亲身经历过那个让所有 SaaS 工程师都头疼的事：**改定价**。

</div>

<div class="p-4 rounded bg-blue-50 border-l-4 border-blue-500">

### AI 时代的痛点被放大几个数量级
收费单位不再是「一个人头一个月多少钱」——而是：

- token 数
- API 调用次数
- GPU 时长

每个客户的 **合同条款、折扣结构、用量阶梯**都可能不一样。

</div>

</div>

<div class="mt-4 p-3 bg-orange-50 border-l-4 border-orange-500 text-sm">

<strong>SaaS vs Token 成本对比</strong>：「SaaS 的成本其实相对稳定，就是服务器成本。但 token 公司确实挺复杂——跟卡本身的情况有关系、跟电的情况有关系、还跟请求量有关系，<strong>峰值有时候会挤到一起</strong>。」

# Metronome 的四层架构

把「发生了什么」和「该怎么收费」 **彻底拆开**：

1. **事件层**——只先记录技术事件（读 / 写 / 思考 / 命中缓存），不挂钱
2. **定价层**——事件值多少钱（可动态）
3. **计费层**——订阅制 / 直接买 API / limit + 超量
4. **折扣层**——合同 / 套餐 / 阶梯优惠

# Token Arbitrage：新的商业模式

<div class="grid grid-cols-2 gap-6 mt-4">

<div>

### 套利的本质
开发者已经在混着用——

- 复杂任务 → **Claude / GPT**
- 简单任务 → **MiniMax / Kimi**

用户的体感：「**全用便宜模型** 和 **全用贵模型** 给他做，看起来区别不大。」

→ 中间就有 **套利空间**

</div>

<div class="p-4 rounded bg-orange-50 border-l-4 border-orange-500">

### 类比：税务审计师

> 你自己报税要交 1 万美金。
> 花 5000 美金雇审计师，他只报了 2000 美金的税。
> **他更专业、懂优化——优化出来的这部分两边各拿一半。**

「Token Arbitrage 好好做的生意就是这样。」

</div>

</div>

<div class="mt-4 p-3 bg-blue-50 border-l-4 border-blue-500 text-sm">

类比国内运营商：1 千兆下行带宽只配 40 兆上行——**普通用户根本感受不到**。Token 上是类似的——本质上 **最后买单的是用户**，只要用户觉得可以，那就是可以的。

</div>

# 智能路由器：套利的进阶玩法

不只是「批发转零售」——而是搭建一个 **智能路由器**：

- 请求进来 → 一个**小模型先判断任务复杂度**
- 简单任务 → 分配给便宜模型
- 真正复杂的 → 才给 Claude / GPT
- 对用户来说是**黑盒**

<div class="mt-4 p-3 bg-green-50 border-l-4 border-green-500 text-sm">
agent 开发者王浩：「最简单的方式入手——拿个简单模型 detect 用户意图、定 metrics、加 threshold——后期抓到用户数据再用 <strong>RL 或 fine-tune</strong> 优化路由小模型。」
</div>

<div class="mt-4 p-3 bg-purple-50 border-l-4 border-purple-500 text-sm">
<strong>模型提供商也有路由模型</strong>——内部有个小模型判断当下任务的难易程度，把它分配给合适的模型，<strong>minimize 它的成本</strong>。
</div>

# 套利能持续吗？短期 vs 长期

<div class="grid grid-cols-2 gap-6 mt-4">

<div class="p-4 rounded bg-red-50 border-l-4 border-red-500">

**Anthropic 已经把这个能力内置到 coding agent 里**——最近加了一个 **Advisor 模式**：

> 「先用贵的模型去判断一下，到底哪些任务可以用便宜的模型做、哪些用贵的模型做。」

大模型厂商会把这种调度做进自己的生态。

</div>

<div class="p-4 rounded bg-green-50 border-l-4 border-green-500">

### ✅ 跨模型空间没被穷尽
**「每家大模型公司只优化自己的模型」**——

跨模型的智能调度不会只是短期机会。但要做的不是只盯定价，还要做：

- 任务跟模型的匹配
- 模型 throughput / latency 判断
- 模型质量 + 任务完成度判断
- 甚至**模型跟硬件的匹配**

</div>

# 美国不缺电，缺的是配电能力

<div class="text-sm opacity-70 mb-4">GMI Cloud 创始人 Alex 在 GTC 现场给的判断：</div>

<div class="grid grid-cols-2 gap-6 mt-4">

<div class="p-4 rounded bg-blue-50 border-l-4 border-blue-500">

### 电价差距没想象中那么大
- 中国工业用电： **0.4 – 0.6 元/度**
- 美国工业用电： **0.8 – 1.2 元/度**

绝对值差异并不大。

</div>

<div class="p-4 rounded bg-red-50 border-l-4 border-red-500">

### 真正的瓶颈是配电
> 「美国不缺电——缺的是 **distribution power（配电能力）**⋯⋯
> 你要从 330kV 一路降到 400V 或者 800V，这事实上是非常冗长的一个过程⋯⋯ **光是拿审批你就爆炸了。**」

</div>

</div>

<div class="mt-4 p-4 bg-green-50 border-l-4 border-green-500">

### 中国的基础设施响应速度
> 中国可以**在西部沙漠里面铺满光伏板**，再通过**特高压电网**把电送到东部的算力集群。

→ 真正拉开差距的是 **基础设施的响应速度**。
