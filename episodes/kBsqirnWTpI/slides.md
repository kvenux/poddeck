# 为什么自己做芯片？为了让端到端模型跑在耳塞里

<div class="grid grid-cols-2 gap-6 mt-4 text-sm">

<div>

### 痛点是什么
- 用 AirPods Pro 在嘈杂环境通话，对方还是听得到背景噪音
- 要么过滤太狠人声变残缺、不自然
- "在拾音 / 把声音从背景噪音里面分出来 / 这件事情上面 / 今天的耳机 / 然后能够达到的水平 / 其实离一个比较理想的状态 / 还是有很大的差距的"

### 解法是什么
- 把声学的 **beamforming → 降噪 → 回声消除 → 人声增强** 四个步骤的分治法**扔掉**
- 换成一个**百万参数级的端到端模型**

</div>

<div>

### 但跑不动
- 几百 K 参数的模型在传统耳机 NPU 上**已经出现巨大的功耗**
- 原因不是算力，是**搬数据**——每秒几百帧、每帧都要把模型全部参数从内存拉到 NPU

<div class="mt-3 p-3 rounded bg-purple-50 border-l-4 border-purple-500">

**自然反问：** 我能不能**不搬数据**？

</div>

<div class="mt-3 p-3 rounded bg-orange-50 border-l-4 border-orange-500">

→ 从 **存算分离的冯诺依曼** 转成 **存算一体** 的架构（像大脑那样，神经元同时承担存储和计算）

</div>

</div>

</div>

# 冯诺依曼 vs 大脑

<div class="text-sm opacity-70 mb-3">2023 年 8 月立项，到 2026 年 5 月上市，闯了三年的怪</div>

<div class="space-y-2 text-sm">

<div class="p-3 rounded bg-blue-50 border-l-4 border-blue-500">

### 计算机的前 80 年
"分治法（程序）+ 程序数据 + 冯诺依曼架构" 构成了一个**特别稳定的三角**——每次只算一小部分，所以存算分离合理。

</div>

<div class="p-3 rounded bg-orange-50 border-l-4 border-orange-500">

### 端到端时代
"解问题的方法 / 就不再是分治法了 / 它已经变成 **数据学习 + 强化学习**"。每次推理需要的是**整个左脑搬到右脑**——这个搬运本身就是最大的功耗。

</div>

<div class="p-3 rounded bg-green-50 border-l-4 border-green-500">

### 大脑的方式
"人脑就是 / 你所有的模型参数 / 在你的神经元里边 / 然后同样的 / 神经元其实也扮演了计算的角色"——**不搬运任何参数**。

</div>

</div>

# 智能家居的三个阶段

<div class="grid grid-cols-3 gap-4 mt-6">

<div class="p-5 rounded bg-gray-50 border-l-4 border-gray-400">

### 阶段一：不可调
<div class="text-sm mt-2 opacity-70">"它其实就没什么可以调的东西"</div>
<div class="mt-4 text-xs">没按钮的马桶、没旋钮的椅子。</div>

</div>

<div class="p-5 rounded bg-blue-50 border-l-4 border-blue-500">

### 阶段二：可调节
<div class="text-sm mt-2 opacity-70">"它长出十几个按钮 / 突然变得可以调节了 / 但它不是智能"</div>
<div class="mt-4 text-xs">十几个按钮的马桶、十几个调节点的人体工学椅。"第一你也不太会调，第二你也不太想得起来你要去调它"</div>

</div>

<div class="p-5 rounded bg-orange-50 border-l-4 border-orange-500">

### 阶段三：自调节
<div class="text-sm mt-2 opacity-70">"它能够感知到你在做的事情 / 然后调节它"</div>
<div class="mt-4 text-xs">看见你过来就自己后退，看见你打游戏就把靠背放下，看见你开会就把座位往前调。**这才是真正的智能。**</div>

</div>

</div>

<div class="mt-6 p-4 rounded bg-purple-50 border-l-4 border-purple-500">

**关键判断：** 今天市面上几乎所有"智能家居"产品都还停在**第二阶段（可调节可预设）**——它不智能，本质上是"可调节可预设的家具"。要进第三阶段，需要 **感知 + 规划 + 控制** 三套能力，它们正在从自动驾驶**溢出**到全家庭。

</div>

# 语言即 TAO：阳萌的世界模型

<div class="grid grid-cols-2 gap-6 mt-4">

<div>

### TAO = Task + Action + Observation

<div class="p-3 rounded bg-blue-50 border-l-4 border-blue-500 text-sm">

- **T (Task)** — 今天你要完成的任务
- **A (Action)** — 每一个说出来的词 = 一个 action
- **O (Observation)** — 因这个 action，世界发生变化后你的观察

</div>

### 为什么语言这么特别
- VLA 模型：从上一个状态 → 推导下一个动作
- 世界模型：从一个动作 → 推导世界变成什么样
- **语言数据是唯一同时记录了 O→A 和 A→O 双向的数据形态**

</div>

<div>
