# 为什么这期值得听

<div class="mt-5 grid grid-cols-3 gap-4 text-left text-[15px] leading-6">

<div class="rounded-lg border-l-4 border-blue-500 bg-blue-50 p-4">

### 团队正在缩小
传统的十余人职能团队，被约 6–7 人的核心 pod 替代；协调成本本身就是生产力变量。
</div>

<div class="rounded-lg border-l-4 border-purple-500 bg-purple-50 p-4">

### 品味正在升值
当制作越来越便宜，决定什么值得做、什么不值得做，反而成为稀缺能力。
</div>

<div class="rounded-lg border-l-4 border-green-500 bg-green-50 p-4">

### 人类工作上移
工程从写代码迁向规划与评审；产品工作从执行迁向愿景、策略和反馈。
</div>

<div class="rounded-lg border-l-4 border-orange-500 bg-orange-50 p-4">

### 推荐不是读心术
过去的系统更多在不透明向量中寻找相关性；LLM 开始把它翻译成人能理解、能调整的主题。
</div>

<div class="rounded-lg border-l-4 border-red-500 bg-red-50 p-4">

### AI 内容需要来源感
平台既不能简单封杀 AI 内容，也不能假装识别永远准确；内容与账号都需要更透明的上下文。
</div>

<div class="rounded-lg border-l-4 border-yellow-500 bg-yellow-50 p-4">

### 规模放大一切
对 4% 用户的早期测试，也可能立即变成公共事件；产品实验必须同时准备沟通策略。
</div>

</div>

# 通才时代，不等于专家消失

<div class="mt-8 grid grid-cols-2 gap-7 text-left">

<div class="rounded-xl border-l-4 border-purple-500 bg-purple-50 p-6">

# 设计师的去向：从角色扩张为判断力

<div class="mt-5 grid grid-cols-3 gap-4 text-left text-[15px] leading-6">

<div class="rounded-lg border-l-4 border-blue-500 bg-blue-50 p-5">

### 原来的边界
视觉与交互设计，影响产品但职称仍属于单一职能。
</div>

<div class="rounded-lg border-l-4 border-purple-500 bg-purple-50 p-5">

### 正在发生
强设计师往往也对产品策略、商业与 go-to-market 有明确意见。
</div>

<div class="rounded-lg border-l-4 border-green-500 bg-green-50 p-5">

### 新的落点
部分设计师和数据科学家转向 Product Staff，扩大决策覆盖面，同时保留独特 craft。
</div>

</div>

<div class="mt-7 rounded-lg border-l-4 border-orange-500 bg-orange-50 p-5 text-left text-[15px] leading-6">
具体例子：Instagram 一位名为 Nate 的高级设计师转入 Product Staff。Adam 也提醒要校正自己的偏见——他本人正是从设计师转成产品负责人。
</div>

<div class="mt-5 text-left text-sm text-slate-500"><b>关键区别：</b>职能名称变弱，不代表设计能力变弱；它可能渗透到更广的决策范围。</div>

<div class="mt-3 text-sm not-italic text-slate-500">— Adam Mosseri，谈当前工具状态</div>

# Token 不是荣誉积分，而是待配置的资源

<div class="mt-6 grid grid-cols-2 gap-6 text-left text-[15px] leading-6">

<div class="rounded-xl border-l-4 border-red-500 bg-red-50 p-5">

### 错误激励
把 token 消耗做成排行榜，容易奖励 token incinerator：花费很大，却没有对应价值。

<div class="mt-4 text-xl italic">"No leaderboards for token spend."</div>
</div>

<div class="rounded-xl border-l-4 border-green-500 bg-green-50 p-5">

### 正确问题
像 GPU、CPU、存储、标注预算和人数一样，比较 <b>dollars in</b> 与 <b>value out</b>。

当前 Instagram 没有限制；Adam 预计未来可能按组织对工程师 ROI 能力的信任设置额度。
</div>

</div>

<div class="mt-6 rounded-lg border-l-4 border-orange-500 bg-orange-50 p-5 text-left text-[15px] leading-6">
一个值得警惕的量级判断：一两年内，强工程师的模型消耗可能接近其薪酬或雇佣成本。价格可能下降，但使用量会先上升，因此总成本会像过山车。
</div>

# 控制权问题：Centaur 还是 Reverse Centaur？

<div class="mt-5 space-y-4 text-[15px] leading-6">
  <div class="rounded-lg border-l-4 border-green-500 bg-green-50 p-4"><b>主持人的 Centaur 类比</b><br>人决定方向，AI 承担力量与执行。</div>
  <div class="rounded-lg border-l-4 border-red-500 bg-red-50 p-4"><b>Reverse Centaur</b><br>AI 决定策略，人只执行系统下发的动作。</div>
